PALESTINE: A LIVING MAP - OFFLINE EDITION

How to open it (no internet needed, nothing to install)

  Windows : double-click "open-map.bat". If Windows asks about PowerShell, choose "Run anyway".
            Your browser opens at http://localhost:5175/ . Close the black window to stop.
  Mac     : double-click "open-map.command" (if it will not open, right-click, Open).
  Linux   : run ./open-map.command in a terminal (needs Python 3).

Why not just double-click index.html? Browsers block a page from reading its own data files when it is opened straight from disk, so the map needs this tiny local server.

What works offline
  - Everything: the timeline, all events, story cards, search, the Follow threads, the animated routes, place names that change by era,
    villages and the Settlements section, the tilted and flat views, night mode, and the optional Illustrated base picture (Filters > Map picture).
  - The map itself (land, sea, roads, borders, lakes and modern names) is drawn from files inside this package.

Limits of this edition
  - The built-in basemap copy goes to a medium level of detail (about 1:250,000 or coarser). Zoomed in further, it is magnified, so small roads and
    streets are missing. The online edition shows more.
  - Web fonts for the page text are not included (your device's own fonts are used instead).

Notes
  - All entries are marked "Under review" unless the owner has verified them; read the sources on each card.
  - Names, dates and places come from the sources listed on each card. Where accounts differ, the card says who says what.
  - Open the About button inside the map for credits and licences.
